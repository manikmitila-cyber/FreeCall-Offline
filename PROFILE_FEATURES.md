# FreeCall Offline — Profile & Account Features

Planned:
- Phone-number based local account identity
- Username and display name
- Profile photo from gallery/camera
- Crop/resize before saving
- Local encrypted profile storage
- Profile discovery over the mesh
- Profile photo transfer over encrypted mesh packets
- Local caching of other users' profile photos
- Call and Message buttons from a user profile

Important:
A phone number is an identity inside the offline mesh. Without Internet/SMS,
global number verification is not possible. Verification can be added later
when an online service is available.
