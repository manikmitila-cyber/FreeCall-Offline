# FreeCall Offline

Offline-first Android communication app project.

Planned/implemented project areas:
- Phone-number + username account identity
- Profile photo selection and display
- Nearby/Mesh user profiles
- Text chat architecture
- Voice call architecture
- Mesh relay architecture
- Local profile persistence

The app is designed for app-to-app communication without relying on ordinary SMS or carrier voice calls. Actual peer-to-peer connectivity must use supported Android local-network APIs and be tested on real devices.
